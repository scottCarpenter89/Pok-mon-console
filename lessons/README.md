# Lesson units

Eighteen units, in order. Each folder has a `README.md` with objectives, a demo to
run, the files to read, a lab, which workbook exercises to set, the errors to expect
and an exit ticket.

| Unit | Course | Title | Big idea |
|---|---|---|---|
| [01](unit01-getting-started) | CS I | Getting the game running | Compile, run, and change a program |
| [02](unit02-variables) | CS I | Variables and data types | A variable is a box with a type |
| [03](unit03-expressions) | CS I | Expressions and the damage formula | Translating maths into code |
| [04](unit04-conditionals) | CS I | Conditionals and the type chart | Programs make decisions |
| [05](unit05-loops) | CS I | Loops | Repetition, and `for` vs `while` |
| [06](unit06-arrays) | CS I | Arrays and 2D arrays | Many values in one variable |
| [07](unit07-methods) | CS I | Methods and decomposition | Breaking a big problem apart |
| [08](unit08-classes) | CS I | Classes and objects | Modelling a thing in code |
| [09](unit09-encapsulation) | CS II | Encapsulation and static vs instance | Objects protect their own rules |
| [10](unit10-inheritance) | CS II | Inheritance, interfaces, polymorphism | Write code that works with what does not exist yet |
| [11](unit11-collections) | CS II | Collections: List and Map | Choosing the right container |
| [12](unit12-files) | CS II | File I/O and exceptions | Programs that talk to the outside world |
| [13](unit13-recursion) | CS II | Recursion | A method that calls itself |
| [14](unit14-searching-sorting) | CS II/III | Searching, sorting and Big-O | Better algorithms beat faster computers |
| [15](unit15-data-structures) | CS III | Data structures and graphs | Stacks, queues, maps, and BFS |
| [16](unit16-design) | CS III | Design patterns and refactoring | Why this code is shaped this way |
| [17](unit17-testing) | CS III | Testing, debugging and version control | Engineering, not just coding |
| [18](unit18-capstone) | CS III | Capstone: retheme and extend | The whole life cycle, as a team |
